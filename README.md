# Branje števcev

Mobilna spletna aplikacija za terensko branje števcev.

Prebere in shrani:
- MKN (8 številk)
- TIP MKN (4 številke)
- leto
- proizvajalca

Omogoča sprotno tabelo ter izvoz v Excel (.xlsx) in CSV.

## GitHub Pages
V repozitoriju odpri **Settings → Pages** in pri **Build and deployment** izberi **Deploy from a branch**, nato **main** in **/(root)** ter klikni **Save**.

Po objavi bo aplikacija dostopna prek GitHub Pages HTTPS povezave.
